# Camada 14: Complementos

**Foco:** habilidades transversais que aumentam velocidade, clareza e confiança em tudo o que está nas outras camadas.

## 1. Lógica e estruturas de dados
- [ ] Arrays, mapas (hash), conjuntos, filas, pilhas, listas ligadas, árvores (noção)
- [ ] Recursão, iteração, ordenação e busca
- [ ] Complexidade (Big-O) no nível prático
- [ ] Resolver problemas pequenos de lógica rápido (strings, datas, contagem, agrupamentos)
- [ ] Estruturas do SPL (`SplStack`, `SplQueue`, `SplObjectStorage`, `ArrayObject`)

## 2. Engenharia de software
- [ ] Clean code: nomes, funções pequenas, tratamento de erros, comentários que explicam o porquê
- [ ] Refatoração segura (com testes)
- [ ] Documentação: README, instruções de execução, PHPDoc, diagramas simples (ER, sequência)
- [ ] Requisitos: ler, ambiguidades, perguntar
- [ ] Estimativa e divisão de tarefas

## 3. Editor e terminal
- [ ] VS Code ou PhpStorm: atalhos, multi-cursor, busca global, refatorar/renomear
- [ ] Depurador integrado (Xdebug), snippets próprios
- [ ] Terminal: histórico, aliases, `grep`, `find`, pipes
- [ ] Git pela linha de comando

## 4. Inglês técnico
- [ ] Ler documentação e mensagens de erro sem tradutor
- [ ] Vocabulário de HTTP, SQL e arquitetura
- [ ] Escrever commits e comentários em inglês claro

## 5. Comparar para entender
- [ ] PHP puro vs Laravel vs Symfony vs Slim: o que é da linguagem e o que é do framework
- [ ] PHP vs Node (Express) vs outras linguagens de back-end: modelos de execução (share-nothing vs long-running)
- [ ] SQL vs ORM vs NoSQL

## 6. Hábitos que sustentam o estudo
- [ ] Estudar com projeto na mão, não só lendo
- [ ] Registrar o que aprendeu (caderno de bugs, resumos)
- [ ] Revisão espaçada das camadas 0 a 3
- [ ] Ensinar o conceito a alguém (ou explicar em voz alta)
